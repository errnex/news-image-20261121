# news-image-20261121

One image that sums up the world's news of Saturday, 21 November 2026: a front page with the date, six lead stories, and 43 more headlines across seven regions, each marked confirmed or reported/developing.

`main.ts` (Node 22, stdlib only, no network) copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`.
